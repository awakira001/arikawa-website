# 有川 一 公式ホームページ

公開URL: https://awakira001.github.io/arikawa-website/

中部学院大学スポーツ健康科学部・有川一の公式ホームページです。GitHub Pagesで公開しています。

## 構成

- `index.html`: サイト本文、デザイン、タブ切り替え処理
- `arikawa_photo_01.jpg`: プロフィール写真
- `robots.txt`: 検索エンジン向けクロール設定
- `sitemap.xml`: 公開URLのサイトマップ

## 安全な更新手順

1. `main` から用途ごとの作業ブランチを作る
2. 作業ブランチでファイルを変更する
3. Pull Requestで差分を確認する
4. 表示、リンク、スマートフォン表示を確認する
5. 問題がなければ `main` にマージする
6. GitHub Pagesへの反映後、公開URLを確認する

## ChatGPTへ更新を依頼するときの情報

- 掲載希望日
- 掲載する出来事・実績
- 掲載先の希望（不明ならChatGPTが提案）
- 正式名称、人数、日付、会場、URL
- 使用する写真と掲載順
- 公開してよい個人情報の範囲

## 運用上の注意

- `main` は公開版として扱い、原則として直接編集しない
- 文章や写真の追加はPull Requestで確認してから公開する
- 画像はWeb向けに縮小・圧縮し、半角英数字のファイル名を使う
- 更新時はページタイトル、説明文、リンク切れも確認する
